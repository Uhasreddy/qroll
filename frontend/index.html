Start an attendance session

Create an event, put the live QR code on the projector, and students check in from their phones.

You need this PIN to see the QR code and attendee list. It is stored only as a salted hash.

How it works

  1. Create: this page calls POST /events on API Gateway, which runs a Lambda function that writes the event to DynamoDB.
  2. Project the QR: the dashboard shows a QR code whose token changes every 30 seconds, so a photo forwarded on WhatsApp stops working.
  3. Scan & check in: students scan with their phone camera, enter name + register number, and DynamoDB blocks duplicates with a conditional write.
  4. Watch live: the dashboard refreshes the list every few seconds; export to CSV when done.

Frontend: Amazon S3 static website · API: Amazon API Gateway (HTTP API) · Logic: AWS Lambda (Python) · Data: Amazon DynamoDB (on-demand, TTL cleanup)
